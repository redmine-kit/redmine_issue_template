# 取り込みと同期

プロジェクトのテンプレートは Redmine に保存します。画面は保存したファイルだけを読み、リポジトリは読みません。そのため、リポジトリが遅くても、つながらなくても、「新しいチケット」は遅くなりません。保存するファイルの取得元は次の 3 つのどれかで、プロジェクトの設定の「チケットテンプレート」タブに、どれを使っているかが出ます。

| 取得元 | ファイルを取り込むタイミング | 編集する場所 |
| --- | --- | --- |
| リポジトリ | プロジェクトのメインのリポジトリを取得したとき、または「インポート」を押したとき | リポジトリ |
| GitHub | [Redmine GitHub](https://github.com/redmine-kit/redmine_github) が、デフォルトブランチへの push を受け取ったとき | GitHub |
| プロジェクトの設定 | タブでファイルを編集したとき | Redmine |

<a id="the-projects-repository"></a>

## プロジェクトのリポジトリ

Redmine がプロジェクトのメインのリポジトリのコミットを取得すると、プラグインはデフォルトブランチのテンプレートフォルダーを読み、保存したファイルと比べます。取得するのは、「コミットを自動取得する」を有効にしてリポジトリを開いたとき、cron から `Repository.fetch_changesets` を実行したとき、Redmine のリポジトリの Web サービスを呼んだときです。ファイルが違えば取り込み直し、フォルダーを最後に変えたリビジョンを記録します。読み込みには Redmine 自身のリポジトリのアダプターを使うので、Redmine が対応するすべての SCM で動きます。

プロジェクトの設定の「インポート」は、取得を待たずに、すぐにフォルダーを読みます。

リポジトリからテンプレートフォルダーがなくなると、リポジトリから取り込んだテンプレートは消えます。プロジェクトの設定で編集したテンプレートは残ります。

<a id="redmine-github"></a>

## Redmine GitHub

[Redmine GitHub](https://github.com/redmine-kit/redmine_github) は、GitHub App で GitHub のリポジトリとつなぎます。デフォルトブランチへの push で `.redmine/ISSUE_TEMPLATE/` か `.github/ISSUE_TEMPLATE/` が変わったという通知が GitHub から届くと、Redmine GitHub はそのフォルダー(ファイルがある最初のもの)を読み、ファイルをこのプラグインに渡します。

```ruby
RedmineIssueTemplate::Importer.import(
  project,
  files: { 'bug_report.yml' => '...', 'config.yml' => '...' },  # フォルダーの中のファイル名 => 内容
  revision: 'c0ffee…',                                          # コミット
  source: 'github',
  folder: '.github/ISSUE_TEMPLATE'
)
```

この呼び出しはプロジェクトのファイルを置き換え、エラーと警告を持つ取り込みの記録を返します。GitHub から取り込んだテンプレートは、Redmine のリポジトリを取得しても置き換えません。「インポート」を押したときだけ置き換えます。

<a id="the-project-settings"></a>

## プロジェクトの設定

リポジトリにテンプレートがないプロジェクト(リポジトリがないプロジェクトも含む)は、タブでファイルを追加、編集、削除します。ファイルはリポジトリに置くものと同じで、テキストのまま編集します。保存するときに取り込みと同じ入力チェックを行い、エラーのあるファイルは保存しません。「プレビュー」は、保存せずに、選択画面でのテンプレートの行と、テンプレートを当てた新しいチケットの入力画面を出します。リポジトリから取り込んだファイルは読み取り専用で表示し、同じプレビューを出します。あとでリポジトリにテンプレートを置くと、次の取得で、編集したものと置き換わります。

<a id="errors-and-warnings"></a>

## エラーと警告

取り込むたびに、すべてのファイルを検証し([検証](format.md#checks))、問題をタブに一覧にします。エラーのあるファイルは選択画面に出しません。警告(Redmine に当たるもののないラベル、プロジェクトにないトラッカーなど)があっても、テンプレートは使えます。
